# Session 1: Fundamentos de LLMs

**Date**: March 13, 2025
**Topic**: Breve historia y fundamentos de la IA generativa
**Duration**: 4 rounds x 5 minutes = 20 minutes active play

## Learning Objectives

After this session, students should be able to:
1. Explain what embeddings, transformers, and foundational models are
2. Identify risks: hallucinations, cognitive dependency, uncritical automation
3. Apply LLM concepts to public sector scenarios

## Scenarios

1. **El Chatbot del Servicio Publico** - LLM selection, hallucination mitigation
2. **El Asistente Legislativo** - Embeddings, semantic search, context window
3. **El Clasificador de Denuncias** - Fine-tuning vs prompting, API costs
4. **El Sistema de Alerta Temprana** - Temperature, sampling, reliability

## Concept Tags

- `transformers` - Understanding transformer architecture
- `attention_mechanism` - How attention works
- `embeddings` - Vector representations of text
- `tokenization` - How LLMs process text
- `hallucination` - Understanding and mitigating hallucinations
- `context_window` - Limitations of context length
- `temperature` - Controlling output randomness
